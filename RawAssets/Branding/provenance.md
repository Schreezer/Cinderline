# Cinderline app icon

Created 2026-09-12 with the built-in image generation tool for the Cinderline iOS build. Original direction: an angular cairn/forge emblem, dark basalt and obsidian, a molten-orange core, sparse teal highlights, strong small-size silhouette, opaque square canvas, no text or existing-IP logo. The generated art was inspected at full resolution. The tool returned a 1254-pixel square; the final native export is 1024 x 1024, opaque RGB PNG.

The source is `CinderlineAppIcon.png`. Its byte-identical copy in `Resources/IOS/Assets.xcassets/AppIcon.appiconset` is the native Xcode app icon; Xcode generates device sizes during packaging. The engine's built-in project asset-catalog lookup selects this directory automatically.
