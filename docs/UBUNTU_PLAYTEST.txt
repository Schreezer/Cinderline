CINDERLINE UBUNTU PLAYTEST

Requirements
  Ubuntu 22.04 or newer on a 64-bit Intel or AMD computer.

Run
  1. Extract the archive.
  2. Open the extracted Cinderline-Ubuntu-x86_64 folder.
  3. Double-click Cinderline.sh and choose Run.

If Ubuntu opens the script as text, open Terminal in the folder and run:
  ./Cinderline.sh

Controls
  Left click or drag        Select units
  Shift + left click       Add or remove a unit from selection
  Double-click             Select visible units of the same type
  Right click              Move, gather ore, attack, or set a rally point
  Mouse wheel              Zoom
  Arrow keys or WASD       Move camera
  Q                        Select all Drudges
  E                        Select the whole army
  Z, then left click       Attack-move
  X                        Stop
  H                        Hold position
  F                        Focus your base
  Space, P, or Esc         Pause or resume
  F5 / F9                  Save / load
  R                        Rematch after a result

Goal
  Gather ore, build production structures, train an army, and destroy the
  opposing Anchor. This is a local skirmish against the computer. The Ubuntu
  playtest uses Cinderline's shared simulation and a lightweight Linux renderer;
  it is not the Unreal presentation used by the macOS and iOS builds.

Troubleshooting
  Run ./Cinderline.sh from Terminal to see an error message. If your desktop is
  not Ubuntu or does not provide X11 compatibility, this playtest may not open.
